 How the Game Works

1. The computer randomly selects a number between 1 and 100.
2. The player enters a number as a guess.
3. If the guess is too low, the game displays "Too Low! Try Higher."
4. If the guess is too high, the game displays "Too High! Try Lower."
5. The player continues guessing until the correct number is found.
6. The game counts the total number of attempts taken.
7. The goal is to guess the correct number in the minimum number of attempts possible.
